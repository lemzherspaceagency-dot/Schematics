# MakerWorld pack v3 (original designs inspired by current trends)

Original designs, not copies of any listed model. Not print-tested yet.

| File | Notes |
|---|---|
| `spider_wand` | Print-in-place spinning spider on a wand. Print upright, no supports; the spider stands on its leg tips. Use a brim. 164 mm tall, fits the A1 mini |
| `glasses_holder` | Desk-edge clamp with a cradle. Set `desk_t` to your tabletop thickness. Print on its side |
| `litter_scoop` | 96x156 mm, fits the bed. Set `slot_w` for your litter (5-6 mm clumping, ~3.5 mm fine) |

Test the spider's spin and the clamp fit first, and adjust the clearance variables (`gap`, `hole_d`, `desk_t`) before you post.
